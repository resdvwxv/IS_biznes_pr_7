# Практическая работа №7

Первое полноценное ООП-приложение. Корпоративный заказ оборудования.

Консольное приложение формирует заказ оборудования для сотрудника: заказ состоит из позиций (товар и количество),
контролирует корректность данных, считает итог и запрещает изменение после подтверждения.

Вариант 6: правило объединения повторного товара, параметр 35 (предел количества в объединённой строке,
константа `OrderItem.MAX_MERGED_QUANTITY`).

## Структура

```
src/ru/edu/pr04/
  Employee.java      сотрудник (record)
  Product.java       товар: id, название, цена > 0
  OrderItem.java     позиция: товар и количество 1..100, правило объединения
  Order.java         заказ: добавление, удаление, итог, подтверждение
  OrderStatus.java   DRAFT / CONFIRMED
  OrderService.java  создание, проверка перед подтверждением, загрузка CSV
  Main.java          запуск на CSV-файле
  SelfCheck.java     самопроверка и граничные случаи
data/sample.csv      открытый набор данных (productId;name;price;quantity)
```

## Сборка и запуск (без Maven)

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr04.SelfCheck
java -cp out ru.edu.pr04.Main data/sample.csv
```

Или одной командой самопроверку: `bash run_selfcheck.sh`

Требуется JDK 17 или новее (используется record).

## Формат CSV

Первая строка — заголовок, поля через `;`: `productId;name;price;quantity`.
Некорректные строки (отрицательная цена, неверный формат, конфликт данных о товаре, нарушение лимитов)
не останавливают программу, а выводятся как `ERROR line N: ...`.
